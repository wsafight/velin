# 值与集合

[English](VALUES.md)

Velin 有五种值，没有浮点。集合是持久化的：更新返回新值。进入运行时状态的每个值都会按数据预算检查。

## 五种值

| 类型 | 运行时形态 | 显示 |
| --- | --- | --- |
| 整数 | `i64` | 十进制，无千分位 |
| 布尔 | `true` / `false` | `true` / `false` |
| 字符串 | UTF-8 文本 | 文本本身 |
| 列表 | 有序元素 | 方括号，逗号分隔 |
| 记录 | 字符串键到值 | 圆括号里稳定顺序的 `key: value` |

没有 `null`、浮点、字节缓冲或用户自定义类型。缺数据要么是运行时错误（`get` 不带回退），要么是显式的回退值。

`==` / `!=` 对每种类型都是确定性的。记录按键比较，不按插入顺序。记录的显示和序列化顺序稳定。

## 整数

算术带检查。溢出和除以零会使当前这次 `run` / `resume` 失败。一元 `-` 取负。没有位运算，也没有取余。

把物理单位留在宿主里，或在脚本看到之前先换成整数（分、毫米、毫秒）。

## 字符串

`"HP: [hp]"` 插入表达式。每种值都有显示形式，所以 `[list(1, 2)]` 合法。`[[` 表示字面开方括号。插值可以嵌套，嵌套插值共享解析预算。

`+` 连接两个字符串。`<` `<=` `>` `>=` 给两个字符串排序。`len(s)` 是字符数。`contains(s, part)` 测子串。

运行时字符串通过 `SharedString` 共享（内部为 `Arc<String>`）。克隆值或机器检查点不会复制文本。`set text = text + "x"` 这类自赋值只在字符串由槽位唯一持有时复用分配；存在别名时，外部可观察的值语义仍保持持久化。

## 列表

```velin
default items = list("torch")
set items = push(items, "key")
first = get(items, 0)
maybe = get(items, 3, "nothing")
```

- 下标是从零开始的整数。
- `push` 追加并返回新列表。
- `get(list, i)` 在缺下标时出错；`get(list, i, fallback)` 不会。
- `put(list, i, value)` 要求下标已存在。
- `remove(list, i)` 要求下标已存在。
- `len` 和 `contains` 用元素个数和成员关系。
- `list(...)` 最多 128 个参数。

忘记把 `push` 的结果赋回去，原来的列表不会变。

结果写回同一源槽位的赋值使用所有权感知 VM 更新。唯一持有的列表或记录在所有失败检查通过后可以修改原分配；真实别名和机器检查点仍保持写时复制，因此这只是执行优化，不改变语言语义。

## 记录

```velin
default hero = record("name", "Ada", "hp", 30)
set hero = put(hero, "hp", get(hero, "hp") - 3)
```

- 构造时键必须是唯一字符串。
- `get(record, "hp")` 缺键会出错，除非提供回退值。
- `put` 更新或插入字段，返回新记录。
- `remove(record, "atk")` 缺键会出错。
- `contains(record, "hp")` 测键是否存在。
- `len` 是字段个数。

## 数据预算

每棵值树最多 4,096 个节点、16 层集合、1 MiB 文本。宿主不能靠 `resume` 或 `set_variable` 注入超大字符串来绕过预算；值在进入时就会被检查。见[资源预算](LIMITS.zh-CN.md)。
