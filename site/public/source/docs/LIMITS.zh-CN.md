# 资源预算

[English](LIMITS.md)

不信任的脚本会在已公布的预算内失败。核心不限制墙上时钟、套接字或写文件：那些仍是宿主的事。本页列出 Velin 自己会拒绝的内容。

## 源码与表达式

| 限制 | 数值 |
| --- | --- |
| 源文件 | 1 MiB |
| 物理行 | 10,000 |
| 嵌套语句块 | 64 |
| 单条表达式 | 64 KiB、512 个 token、32 层括号 |
| 插值嵌套 | 32 层 |
| 共享的插值工作量 | 256 KiB 和 2,048 个 token |

制表符会被拒绝。每层缩进恰好四个空格。

## 值

| 限制 | 数值 |
| --- | --- |
| 一棵值树的节点 | 4,096 |
| 集合嵌套 | 16 层 |
| 一棵值树中的文本 | 1 MiB |
| `list(...)` 的参数 | 128 |

经 `set_variable` 或 `resume` 传入的每个值都按同一预算检查。

## 字节码与 VM

| 限制 | 数值 |
| --- | --- |
| 控制流操作 | 100,000 |
| 表达式块 | 100,000 |
| 槽位 | 65,536 |
| 常量值节点 | 100,000 |
| 常量和槽位文本 | 16 MiB |
| 每个表达式块的操作 | 4,096 |
| 表达式栈高 | 1,024 |
| 每条宿主指令的参数 | 128 |
| 每次 `run` / `resume` 的立即步数 | 10,000 |

没有 `perform` 的循环会碰到立即步数预算，返回错误，而不是一直占着调用方。

## 工具上限

这些不是语言语义，只作用于特定工具：

| 工具 | 上限 |
| --- | --- |
| CLI / Playground 输出 | 1 MiB |
| Playground 宿主效果 | 1,000 |
| Playground 回复 JSON | 1 MiB |
| LSP JSON-RPC 正文 | 4 MiB |
| LSP 头 | 合计 64 KiB，每行 8 KiB |

## 宿主仍须限制的

Velin 不会打开文件或发送数据包。宿主仍应允许名单命令名、检查参数，并施加自己的时间、输出、网络和存储预算。见[宿主协议](HOST.zh-CN.md)。
