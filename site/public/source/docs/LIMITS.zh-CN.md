# 资源预算

[English](LIMITS.md)

不信任的脚本会在已公布的预算内失败。核心不限制墙上时钟、套接字或写文件：那些仍是宿主的事。本页列出 Velin 自己会拒绝的内容。

## 源码与表达式

| 限制 | 数值 |
| --- | --- |
| 源文件 | 1 MiB |
| 物理行 | 10,000 |
| 嵌套语句块 | 64 |
| 单条表达式 | 64 KiB、512 个 token、32 层括号 |
| 插值嵌套 | 32 层 |
| 共享的插值工作量 | 256 KiB 和 2,048 个 token |

制表符会被拒绝。每层缩进恰好四个空格。

## 值

| 限制 | 数值 |
| --- | --- |
| 一棵值树的节点 | 4,096 |
| 集合嵌套 | 16 层 |
| 一棵值树中的文本 | 1 MiB |
| 一台 Machine 保留的值 | 100,000 |
| 一台 Machine 保留的文本 | 16 MiB |
| 一次宿主载荷中的值 | 100,000 |
| 一次宿主载荷中的文本 | 16 MiB |
| `list(...)` 的参数 | 128 |

经 `set_variable` 或 `resume` 传入的每个值都按同一单值预算检查。VM 还会统计整个 frame 和每次产出的宿主载荷；结构共享的值按逻辑大小计数，因此上限不依赖具体分配方式。

## 字节码与 VM

默认 `ExecutionPolicy` 还会跨执行调用应用以下运行时预算：

| 限制 | 默认值 |
| --- | --- |
| 每台 Machine 生命周期累计 fuel | 10,000,000 |
| 每次 `run` / `resume` / batch 的立即 fuel | 10,000 |
| 每台 Machine 生命周期宿主效果 | 1,000 |
| VM 调用深度 | 64 |
| 宿主队列事件 / 值 / 文本 | 1,024 / 1,000,000 / 64 MiB |

| 限制 | 数值 |
| --- | --- |
| 控制流操作 | 100,000 |
| 表达式块 | 100,000 |
| 槽位 | 65,536 |
| 常量值节点 | 100,000 |
| 常量和槽位文本 | 16 MiB |
| 每个表达式块的操作 | 4,096 |
| 每个表达式块的寄存器 | 1,024 |
| 每条宿主指令的参数 | 128 |
| 每次 `run` / `resume` 的立即步数 | 10,000 个 fuel 单位 |

没有 `perform` 的循环会碰到立即 fuel 预算，返回错误，而不是一直占着调用方。

立即 fuel 在每次执行调用时重置；累计 fuel 和宿主效果数量会跨 `run` / `resume` 保留，并由 `Machine::clone` 复制；`restart` 会清零它们。宿主可以通过 `ExecutionPolicy` 配置这些上限。

## 工具上限

这些不是语言语义，只作用于特定工具：

| 工具 | 上限 |
| --- | --- |
| CLI / Playground 输出 | 1 MiB |
| CLI / Playground 宿主效果 | 1,000 |
| Playground 回复 JSON | 1 MiB |
| Playground Worker 请求 | 5 秒 |
| LSP JSON-RPC 正文 | 4 MiB |
| LSP 头 | 合计 64 KiB，每行 8 KiB |

## 宿主仍须限制的

Velin 不会打开文件或发送数据包。宿主仍应允许名单命令名、检查参数，并施加自己的时间、输出、网络和存储预算。见[宿主协议](HOST.zh-CN.md)。
